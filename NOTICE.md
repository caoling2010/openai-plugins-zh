# Notice

This project is an unofficial Chinese index for Codex plugins.

## Data Source

Plugin metadata is synchronized from the public OpenAI plugins repository:

https://github.com/openai/plugins

The generated Chinese descriptions are translations or summaries of the
source plugin descriptions. They are provided for search, discovery, and
learning convenience only. For authoritative and up-to-date information, use
the original plugin manifest, source repository, and official provider pages.
