# 推广流程

这个目录用于准备 OpenAI Plugins 中文索引的社区发布素材。

目标不是自动群发，而是把文案、链接和检查项提前整理好。每次发布前先生成草稿，再根据具体社区规则微调，最后由维护者手动确认发布。

## 推荐顺序

1. GitHub 仓库内部
   - 确认 About description 和 Website 已填写。
   - README 顶部保留在线访问链接。
   - 发布第一个 Release，说明项目解决的问题和当前功能。

2. 国内开发者社区
   - V2EX：适合发在 `分享创造`、`程序员` 或相关节点。
   - 掘金：适合写成短文，重点讲痛点和实现方式。
   - SegmentFault：适合偏工具介绍和开源项目分享。
   - 开源中国：适合开源项目推荐。
   - 知乎：适合回答“Codex 插件如何选择/有哪些插件”类问题时自然引用。

3. 后续补充
   - 根据反馈补 FAQ、截图或使用案例。
   - 有明显更新时再二次发布，避免短期重复刷屏。

## 一键生成草稿

```bash
npm run promotion:posts
```

生成结果会输出到终端，可以复制到对应社区后再人工调整。

## 发布原则

- 不冒充 OpenAI 官方项目。
- 不使用夸张标题或营销话术。
- 每个平台只发一次首发帖，后续有实质更新再跟进。
- 发布前阅读社区规则，确认允许开源项目分享。
- 帖子里说明项目解决的具体痛点，而不是只丢链接。
