# 发布文案模板

## 通用短文案

我做了一个 OpenAI Codex 插件中文索引：

https://caoling2010.github.io/openai-plugins-zh/

Codex 插件越来越多，但官方说明主要是英文。这个页面把插件说明整理成中文，同时保留 MCP、CLI、Worktrees、Schema、SwiftUI 等核心技术词的英文原文，方便继续搜索官方资料。

目前支持关键词搜索、官方分类浏览、7 天内新增插件 `New` 标记，并会自动同步公开的 OpenAI 插件列表。

这是非官方项目，数据来源是公开的 `openai/plugins` 仓库。欢迎试用，也欢迎反馈翻译或分类问题。

## V2EX

标题：

做了一个 OpenAI Codex 插件中文索引，方便按中文说明搜索插件

正文：

最近 Codex 插件越来越多，但官方列表里的说明主要是英文。实际找插件时，经常要点开一个个看，再复制说明去翻译，效率不太高。

我做了一个中文索引页：

https://caoling2010.github.io/openai-plugins-zh/

它主要做几件事：

- 插件名称保留英文，说明翻译成中文
- MCP、CLI、Worktrees、Schema、SwiftUI 等技术词保留英文原文
- 支持关键词搜索和官方分类浏览
- 7 天内新增插件会显示 `New`
- 每天自动同步公开的 OpenAI 插件列表

项目是非官方的，数据来源是公开的 `openai/plugins` 仓库。希望能帮中文开发者更快判断每个插件适合什么任务。

如果你发现翻译不准确、分类不直观，欢迎提 issue。

## 掘金 / SegmentFault

标题：

给 Codex 插件做了一个中文索引：中文说明、关键词搜索、自动同步

正文：

Codex 插件生态开始变多之后，一个很实际的问题是：插件名称通常保留英文没问题，但说明也全是英文时，很多中文开发者需要不断复制粘贴到翻译工具里，才能判断这个插件是否适合当前任务。

这个项目尝试解决这个小痛点：

https://caoling2010.github.io/openai-plugins-zh/

页面会展示插件英文名、中文说明、官方分类、关键词和来源链接。核心技术名词会保留英文，例如 MCP (Model Context Protocol)、CLI、Worktrees、Schema、SwiftUI，方便继续搜索官方资料。

目前功能：

- 关键词搜索
- 按官方分类浏览
- 7 天内新增插件 `New` 标记
- 自动同步公开 OpenAI 插件列表
- 每张卡片保留来源链接

项目仓库：

https://github.com/caoling2010/openai-plugins-zh

这是非官方中文索引，中文说明仅用于检索和学习参考，权威信息仍以原始仓库和官方页面为准。
