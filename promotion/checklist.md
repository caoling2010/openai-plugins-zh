# 发布检查清单

## 发布前

- [ ] 页面可以正常打开：<https://caoling2010.github.io/openai-plugins-zh/>
- [ ] GitHub 仓库 README 顶部有在线访问链接。
- [ ] About 区域有简短介绍和 Website 链接。
- [ ] 帖子说明这是非官方中文索引。
- [ ] 帖子说明数据来源是公开的 `openai/plugins` 仓库。
- [ ] 标题不夸张，不像广告。
- [ ] 内容包含实际痛点：英文插件说明理解成本高、复制翻译麻烦、插件越来越多难筛选。
- [ ] 内容包含实际功能：中文说明、关键词搜索、分类浏览、新插件标记、自动同步。
- [ ] 没有泄露 API key、账号信息或仓库 Secrets。

## 发布时

- [ ] 选择合适分区或话题。
- [ ] 按社区语气微调文案。
- [ ] 先预览再发布。
- [ ] 最终发布按钮由维护者手动点击。

## 发布后

- [ ] 记录发布时间、平台和链接。
- [ ] 收集反馈和问题。
- [ ] 如果有人指出翻译或分类问题，优先修正页面。
- [ ] 避免短时间在同一社区重复发布。
